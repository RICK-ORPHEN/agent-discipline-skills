# Claims, measured

Advice about instructing coding agents travels fast: a line to add to `CLAUDE.md`, a way to
phrase a rule, a number from a paper. Most of it is passed on without anyone running it again.

Each directory here takes one claim that was circulating, writes down the test and the decision
rule **before** running anything, runs it, and publishes what came out — including "no
difference" and "we could not test what the claim is really about".

These are small tests: one model family, a short task, 15 sessions per arm unless a directory
says otherwise. A result here is one data point about the claim, not a ruling on the paper
behind it. Each `PRE-REGISTERED.md` lists how the test differs from the original.
